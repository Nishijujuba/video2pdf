# Delivery Quality Context

Status: target-only. It succeeds the active Final Acceptance Context only at the Global Gate Cutover.

This target context owns canonical delivery-blocking quality policy, Language Profiles, Role Projections, semantic decision ownership, evidence sufficiency, implementation conformance, precompile quality judgments, text sealing, rendered-text reconciliation, and final semantic materialization.

## Delivery Quality Rule Catalog

The strict, versioned, fingerprinted sole normative source for delivery-blocking quality rules. Each rule has one stable identity, affirmative observable requirement, closed violations, repeatable exceptions, explicit Language Profiles, and evidence requirements.

## Language Profile

A closed contract describing the primary reader language, permitted supporting languages, reader contract, and terminology policy. Workflow input binds a profile explicitly; roles cannot infer one from prose.

## Role Projection

A versioned, fingerprinted deterministic view of canonical rules for one consumer role. A guidance projection distributes immutable authoring or repair guidance and has no gate authority. An evaluation projection assigns rules to one Primary Semantic Decision Owner and cannot rewrite policy.

## Primary Semantic Decision Owner

The one independent semantic role authorized to decide a blocking rule for the current artifact generation. Guidance, authoring, integration, and repair roles have no pass authority for artifacts they changed.

## Delivery Quality Waiver

A human-governed, scope-bound, time-bounded run-specific departure from one or more registered violations. A Waiver cannot broaden catalog exceptions or change canonical policy.

## Delivery Quality Contract Gap

A potentially blocking problem that cannot map to a registered rule, violation, exception, transformation, evidence identity, or Language Profile. It blocks materialization until explicit human policy disposition.

## Delivery Quality Conformance Corpus

The independently versioned qualification contract containing the required per-profile semantic minimal pairs and deterministic mechanical mutations. It derives from the Rule Catalog and cannot add policy.

## Delivery Quality Conformance Report

The provider-materialized implementation-qualification result bound to exact catalog, projection, corpus, implementation, adapter, Reviewer runtime, semantic attempts, and mechanical cases. It has no video-delivery, Acceptance Report, or runtime-activation authority.

## Semantic Variance

A blocking conformance result recorded when isolated attempts for the same case disagree on classification, violation, exception, or evidence locator.

## Migration boundary

The target migration ledger binds active Acceptance Criteria v1 identities to future canonical rule identities and decision owners. Its presence does not change active Legacy Final Acceptance authority. `Acceptance Report v2` remains the future sole final semantic delivery decision after the Global Gate Cutover.
